## AlternativeTo (alternativeto.net/manage-item/)

**Name:** Nanodoc

**Tagline (short description):**
Free PDF editor that runs entirely on your device. Combine, edit, sign, and
redact PDFs with no paywall, no watermark, and no account.

**Description:**
Nanodoc is a 100% free PDF editor that works in the browser or as a free
desktop app for Mac and Windows. All processing happens locally, so files are
never uploaded to a server.

Tools: combine PDFs, delete and extract pages, add text and highlights, stamps
and drawn signatures, fillable form fields, true redaction (content is removed
and then verified gone, not just covered with a box), and Stitch, which places
multiple PDF pages onto one canvas and exports them as a single sheet.

Honest limits: Nanodoc is pixel-based, so it does not rewrite existing text,
convert file formats, or OCR. It is an editor, not a converter.

**Suggested "alternative to":** Adobe Acrobat, Smallpdf, iLovePDF, Sejda,
PDF-XChange Editor, Bluebeam Revu

**Tags:** pdf-editor, pdf-tools, privacy, no-registration, free

**License field:** Free • Open Source (AGPL-3.0). Source:
github.com/markschwab17/nanodoc

## Product Hunt

**Name:** Nanodoc

**Tagline (60 chars):**
The free PDF editor that never uploads your files

**Description:**
PDF paywalls are everywhere: sign up to merge, pay to redact, watermark on
export. Nanodoc is the other way. Combine PDFs, manage pages, add text and
signatures, build fillable forms, and apply true verified redaction, free, in
your browser, with every file processed on your own device. There is also a
Stitch tool that places pages onto one canvas and exports one sheet, which
nothing else in the free tier of any tool does. No account, no watermark, no
trial clock. Desktop apps for Mac and Windows are free too.

**First comment (from the maker):**
I built Nanodoc because PDFs are everyday paperwork (school forms, medical
forms, potluck sign-ups) and interacting with a file type this common should
not need a subscription. Everything runs locally via WebAssembly, which is also
why it can be free: there are no servers doing your processing. Honest limits,
so nobody is surprised: it is pixel-based, so it does not rewrite existing
text, convert formats, or OCR. If you hit a bug or a missing feature, tell me
and I will fix it.
